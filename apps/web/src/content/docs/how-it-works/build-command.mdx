## Build Command

The `build` command generates all your portfolio artifacts from `DEVSYNC.json`.

<Aside type="note">This command is primarily intended for GitHub Actions, but you can run it locally if you have Bun and Puppeteer installed.</Aside>

<Steps>

1. **Install dependencies** using `bun install`.

2. **Build the project** using `bun run build`.

3. **Validate `DEVSYNC.json`** to ensure configuration is correct.

4. **Build CV for each language** - If `devsync.pathToCompiledCV` is set in `package.json`, the PDF is generated from the compiled CV HTML at that path. If it's not set, the CLI generates the CV itself from `DEVSYNC.json`. Both paths write to the same output (`public/{name}-{lang}.pdf`).

5. **Create LinkedIn profile** for each language configured.

6. **Create GitHub profile** using the `defaultLang`. The style is controlled by `devsync.githubProfileStyle` in `package.json` — `"default"` (full profile) or `"minimal"` (compact).

7. **Create academics profile** using the `defaultLang`.

</Steps>

## What Gets Generated

After running `build`, you'll have:

- **CV PDF** - Generated from HTML for each language
- **LinkedIn markdown** - Formatted profile for LinkedIn
- **GitHub Profile README** - Your `README.md` for GitHub profile
- **Academics profile** - Academic credentials in markdown
